## Dynamic Color System Implementation

### Major Changes

**Replaced all hardcoded colors with dynamic CSS variables** across the entire template system to ensure generated projects properly adapt to ANY color palette selected in the UI builder.

### What Changed

#### 🎨 Color System Overhaul
- Replaced 150+ hardcoded color values with dynamic CSS/HSL variables
- All templates now use consistent color tokens that adapt to selected palettes
- Fixed critical contrast issues where text was invisible on certain backgrounds

#### 📦 Updated Templates

**Common Components:**
- `Hero.tsx` - Replaced all `text-black`, `bg-yellow-400` with dynamic variables
- `LoginForm.tsx` - Updated form styling to use `bg-card`, `text-foreground`
- `SignupForm.tsx` - Fixed password strength indicators with dynamic colors
- `AuthExample.tsx` - Updated gradients and error displays
- `NotFoundPage.tsx` - Fixed terminal-style 404 page colors
- `GettingStarted.tsx` - Updated command reference styling

**Framework Templates:**
- Next.js `not-found.tsx` - 27 color replacements
- Vue `Counter.vue` - 6 color replacements  
- Svelte `Counter.svelte` - 6 color replacements

- Vite `globals.css` - 7 color replacements

**Plugin Templates:**

**Widget Components:**
